# Sonetix · Páginas web a la medida

Página comercial de Sonetix: creación de páginas web personalizadas para cada negocio y sostenimiento mensual.

Sitio estático: solo necesita `index.html`.

- `index.html`: versión principal (oscura, interactiva, con selector de color rojo/violeta).
- `versiones/`: alternativas (estilo claro del prototipo y primer intento oscuro en rojo).

Antes de publicar, edita el bloque `CONFIG` al inicio del script: número de WhatsApp, precios y textos.

Publicar en Vercel: importar este repositorio, Framework Preset = "Other", sin comando de build.
